# DRC Halftone Web: Hosted Studio with Accounts and Saved Projects — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the DRC Halftone browser studio off the OpenAI Sites runtime onto Cloudflare Workers, add credentialed signup, and give each user a library of reopenable saved projects.

**Architecture:** A Vite React SPA is served from Workers static assets. A Hono Worker handles `/api/*` only, via `run_worker_first`. Identity and file storage come from `better-auth-cloudflare` on D1 (Drizzle) with R2. The halftone engine stays pure and client-side: only user-supplied source artwork and a settings row are persisted, never renders.

**Tech Stack:** Vite 8, React 19, Hono, `better-auth` + `better-auth-cloudflare` v0.3.1, Drizzle ORM 0.45.2, Cloudflare D1 + R2 + Workers static assets, Tailwind 4, Vitest, `@cloudflare/vitest-pool-workers`, Playwright.

**Spec:** `docs/specs/2026-07-27-halftone-web-hosted-workspaces-design.md`. Read it before Task 1.

## Global Constraints

Every task's requirements implicitly include this section.

- Node `>=22.13.0`. Verified present: v22.22.0, npm 10.9.4.
- **The auth instance is created per request, never at module scope.** A module-level singleton holds a D1 write lock while the next instance blocks on it, producing 33-second hangs and phantom 503s.
- **Every project query filters on `userId`.** Session-present is not owns-this-row. Cross-user access returns 404, never 403 and never a row.
- Rate-limit windows are `>= 60` seconds.
- No KV in v1. D1 only.
- `maxFileSize` 15 MB. `allowedTypes` `.png`, `.jpg`, `.jpeg`, `.webp`. Per user: 25 artworks, 100 projects. Enforced server-side.
- Renders and plates are never persisted. Only user-supplied source artwork, a 320px thumbnail, and a settings row.
- The engine (`src/studio/halftone.ts`) never imports auth, session, or `fetch`.
- The studio is fully usable anonymous. Auth gates saving only.
- Default branch `main`. Branch prefixes limited to `feat`, `fix`, `chore`, `task`, `backup`.
- Combined app is GPL-3.0. Do not remove `LICENSE`.

`src/studio/settings-schema.ts`:

```ts
import { PLATES, type DotShape, type HalftoneSettings } from "./halftone";

const DOT_SHAPES: DotShape[] = ["round", "square", "diamond", "line"];

const MAX_CELL_SIZE = 256;

export type ParseResult =
  | { ok: true; value: HalftoneSettings }
  | { ok: false; field: string };

const fail = (field: string): ParseResult => ({ ok: false, field });

function clampTo(value: number, min: number, max: number) {
  return Math.min(max, Math.max(min, value));
}

function isFiniteNumber(value: unknown): value is number {
  return typeof value === "number" && Number.isFinite(value);
}

export function parseSettings(input: unknown): ParseResult {
  if (typeof input !== "object" || input === null) return fail("settings");
  const raw = input as Record<string, unknown>;

  if (!isFiniteNumber(raw.cellSize) || raw.cellSize <= 0 || raw.cellSize > MAX_CELL_SIZE) {
    return fail("cellSize");
  }
  if (!isFiniteNumber(raw.contrast)) return fail("contrast");
  if (!isFiniteNumber(raw.exposure)) return fail("exposure");
  if (!isFiniteNumber(raw.opacity)) return fail("opacity");
  if (typeof raw.invert !== "boolean") return fail("invert");
  if (typeof raw.dotShape !== "string" || !DOT_SHAPES.includes(raw.dotShape as DotShape)) {
    return fail("dotShape");
  }

  if (typeof raw.angles !== "object" || raw.angles === null) return fail("angles");
  if (typeof raw.visible !== "object" || raw.visible === null) return fail("visible");

  const rawAngles = raw.angles as Record<string, unknown>;
  const rawVisible = raw.visible as Record<string, unknown>;

  const angles = {} as HalftoneSettings["angles"];
  const visible = {} as HalftoneSettings["visible"];

  for (const plate of PLATES) {
    const angle = rawAngles[plate];
    if (!isFiniteNumber(angle)) return fail(`angles.${plate}`);
    angles[plate] = ((angle % 360) + 360) % 360;

    const shown = rawVisible[plate];
    if (typeof shown !== "boolean") return fail(`visible.${plate}`);
    visible[plate] = shown;
  }

  return {
    ok: true,
    value: {
      cellSize: raw.cellSize,
      contrast: clampTo(raw.contrast, 0, 4),
      exposure: clampTo(raw.exposure, -1, 1),
      opacity: clampTo(raw.opacity, 0, 1),
      dotShape: raw.dotShape as DotShape,
      invert: raw.invert,
      angles,
      visible,
    },
  };
}
```

import type { D1Database, IncomingRequestCfProperties, R2Bucket } from "@cloudflare/workers-types";
import { betterAuth } from "better-auth";
import { withCloudflare } from "better-auth-cloudflare";
import { drizzle } from "drizzle-orm/d1";
import * as schema from "../db/schema";

export type Bindings = {
  ASSETS: Fetcher;
  DATABASE: D1Database;
  BUCKET: R2Bucket;
  BETTER_AUTH_SECRET: string;
};

/**
 * Create a Better Auth instance.
 *
 * MUST be called once per request. A module-scope singleton holds a D1 write
 * lock while the next instance blocks on it, which surfaces as multi-second
 * hangs and phantom 503s. See docs/specs/2026-07-27-*.md section 8.
 */
export function createAuth(
  env?: Bindings,
  cf?: IncomingRequestCfProperties,
  baseURL?: string,
) {
  const db = env ? drizzle(env.DATABASE, { schema }) : ({} as never);

  return betterAuth({
    baseURL,
    secret: env?.BETTER_AUTH_SECRET,
    ...withCloudflare(
      {
        autoDetectIpAddress: true,
        geolocationTracking: false,
        cf: cf ?? {},
        d1: env ? { db, options: { usePlural: true } } : undefined,
      },
      {
        emailAndPassword: { enabled: true },
        user: {
          additionalFields: {
            signupSource: { type: "string", required: false },
          },
        },
        rateLimit: {
          enabled: true,
          window: 60,
          max: 100,
        },
      },
    ),
  });
}
```

    thumbId?: unknown;

    return c.json({ error: "invalid_name" }, 400);
  }

    return c.json({ error: "invalid_sourceId" }, 400);
  }

  const parsed = parseSettings(body.settings);
  if (!parsed.ok) return c.json({ error: "invalid_settings", field: parsed.field }, 400);

  const db = drizzle(c.env.DATABASE, { schema });
  const counted = await db.all<{ n: number }>(
    sql`select count(*) as n from halftoneProjects where userId = ${userId}`,
  );
  if ((counted[0]?.n ?? 0) >= MAX_PROJECTS_PER_USER) {
    return c.json(
      { error: "project_limit", limit: MAX_PROJECTS_PER_USER },
      409,
    );
  }

  const now = new Date();
  const row = {
    id: crypto.randomUUID(),
    userId,
    sourceId: body.sourceId,
    thumbId: typeof body.thumbId === "string" ? body.thumbId : null,
    name: body.name.trim().slice(0, 120),
    settings: JSON.stringify(parsed.value),
    registration: body.registration !== false,
    createdAt: now,
    updatedAt: now,
  };

  await db.insert(halftoneProjects).values(row);
  return c.json(serialize(row), 201);
});

projects.get("/:id", async (c) => {
  const userId = await requireUserId(c);
  if (!userId) return c.json({ error: "unauthorized" }, 401);

  const db = drizzle(c.env.DATABASE, { schema });
  const [row] = await db
    .select()

    .where(and(eq(halftoneProjects.id, c.req.param("id")), eq(halftoneProjects.userId, userId)))
    .limit(1);

  if (!row) return c.json({ error: "not_found" }, 404);
  return c.json(serialize(row));
});

projects.patch("/:id", async (c) => {
  const userId = await requireUserId(c);
  if (!userId) return c.json({ error: "unauthorized" }, 401);

  const body = await c.req.json<{ name?: unknown; settings?: unknown; registration?: unknown }>();
  const patch: Partial<typeof halftoneProjects.$inferInsert> = { updatedAt: new Date() };

  if (body.settings !== undefined) {
    const parsed = parseSettings(body.settings);
    if (!parsed.ok) return c.json({ error: "invalid_settings", field: parsed.field }, 400);
    patch.settings = JSON.stringify(parsed.value);
  }
  if (typeof body.name === "string" && body.name.trim() !== "") {
    patch.name = body.name.trim().slice(0, 120);
  }
  if (typeof body.registration === "boolean") patch.registration = body.registration;

  const db = drizzle(c.env.DATABASE, { schema });
  const updated = await db
    .update(halftoneProjects)
    .set(patch)
    .where(and(eq(halftoneProjects.id, c.req.param("id")), eq(halftoneProjects.userId, userId)))
    .returning();

  if (updated.length === 0) return c.json({ error: "not_found" }, 404);
  return c.json(serialize(updated[0]));
});

projects.delete("/:id", async (c) => {
  const userId = await requireUserId(c);
  if (!userId) return c.json({ error: "unauthorized" }, 401);

  const db = drizzle(c.env.DATABASE, { schema });
  const [row] = await db
    .select()
    .from(halftoneProjects)
    .where(and(eq(halftoneProjects.id, c.req.param("id")), eq(halftoneProjects.userId, userId)))
    .limit(1);

  if (!row) return c.json({ error: "not_found" }, 404);

  // Artwork is shared across variants of the same piece. Only reclaim storage
  // when this was the last project pointing at it.
  const siblings = await db.all<{ n: number }>(
    sql`select count(*) as n from halftoneProjects
        where sourceId = ${row.sourceId} and userId = ${userId} and id != ${row.id}`,
  );
  const orphaned = (siblings[0]?.n ?? 0) === 0;

  // R2 first, then D1. The reverse order loses the pointer to the object and
  // leaks it silently. This order can leave a row whose source is gone, which
  // the studio already renders as a handled "source unavailable" state.
  if (orphaned) {
    const origin = new URL(c.req.url).origin;
    const deleteFile = (fileId: string) =>
      c
        .get("auth")
        .handler(
          new Request(`${origin}/api/auth/files/delete`, {
            method: "POST",
            headers: {
              "content-type": "application/json",
              cookie: c.req.header("cookie") ?? "",
            },
            body: JSON.stringify({ fileId }),
          }),
        )
        .catch(() => undefined);

    await deleteFile(row.sourceId);
    if (row.thumbId) await deleteFile(row.thumbId);
  }

  await db
    .delete(halftoneProjects)
    .where(and(eq(halftoneProjects.id, row.id), eq(halftoneProjects.userId, userId)));

  return c.body(null, 204);
});

export default projects;
```

Two invariants are load-bearing here.

Every read, update, and delete carries `eq(halftoneProjects.userId, userId)` in its `where`. That is what makes a cross-user request a 404 instead of a leak.

Deletion reclaims R2 before D1, and only when no sibling project shares the `sourceId`. Deleting D1 first would strand the object with nothing pointing at it. Deleting artwork unconditionally would blank out every other variant of the same piece, which is precisely the workflow the separate projects table exists to support.

export async function makeThumbnail(
  source: HTMLImageElement | HTMLCanvasElement,
  maxEdge = 320,
): Promise<Blob> {
  const width = source instanceof HTMLImageElement ? source.naturalWidth : source.width;
  const height = source instanceof HTMLImageElement ? source.naturalHeight : source.height;
  const scale = Math.min(1, maxEdge / Math.max(width, height));

  const canvas = document.createElement("canvas");
  canvas.width = Math.max(1, Math.round(width * scale));
  canvas.height = Math.max(1, Math.round(height * scale));

  const context = canvas.getContext("2d");
  if (!context) throw new Error("Could not create a preview for this artwork.");
  context.drawImage(source, 0, 0, canvas.width, canvas.height);

  return new Promise((resolve, reject) => {
    canvas.toBlob(
      (blob) => (blob ? resolve(blob) : reject(new Error("Preview generation failed."))),
      "image/jpeg",
      0.8,
    );
  });
}

export type Project = {
  id: string;
  name: string;
  sourceId: string;
  thumbId: string | null;
  settings: HalftoneSettings;

  createdAt: number;
  updatedAt: number;

export class ApiError extends Error {
  constructor(message: string, readonly status: number, readonly field?: string) {
    super(message);
  }
}

async function unwrap(response: Response) {
  if (response.ok) return response;
  const body = await response.json().catch(() => ({}) as Record<string, unknown>);
  const error = String(body.error ?? "request_failed");
  const messages: Record<string, string> = {
    unauthorized: "Sign in to save projects.",
    invalid_settings: "Those settings are out of range.",
    invalid_name: "Give the project a name.",
    project_limit: `You have reached the ${body.limit ?? 100} project limit. Delete one to save another.`,
    not_found: "That project no longer exists.",
  };
  throw new ApiError(messages[error] ?? error, response.status, body.field as string | undefined);
}

export async function createProject(input: {
  name: string;
  sourceId: string;
  thumbId?: string | null;
  settings: HalftoneSettings;
  registration: boolean;
}): Promise<Project> {

      method: "POST",
      headers: { "content-type": "application/json" },
      body: JSON.stringify(input),
    }),
  );
  return response.json();
}

  const response = await unwrap(await fetch("/api/projects"));
  const body: { projects: Project[] } = await response.json();
  return body.projects;
}

export async function deleteProject(id: string): Promise<void> {
  await unwrap(await fetch(`/api/projects/${id}`, { method: "DELETE" }));

import { useCallback, useEffect, useState } from "react";
import { useNavigate } from "react-router";
import authClient from "../auth/client";
import { deleteProject, listProjects, type Project } from "../projects/api";

export default function Projects() {
  const navigate = useNavigate();
  const [projects, setProjects] = useState<Project[]>([]);
  const [thumbs, setThumbs] = useState<Record<string, string>>({});
  const [error, setError] = useState<string | null>(null);
  const [loading, setLoading] = useState(true);

  const refresh = useCallback(async () => {
    setLoading(true);
    try {
      setProjects(await listProjects());
      setError(null);
    } catch (caught) {
      setError(caught instanceof Error ? caught.message : "Could not load your projects.");
    } finally {
      setLoading(false);
    }
  }, []);

  useEffect(() => {
    void refresh();
  }, [refresh]);

  useEffect(() => {
    let cancelled = false;
    const urls: string[] = [];

    (async () => {
      for (const project of projects) {
        if (!project.thumbId || thumbs[project.id]) continue;
        const result = await authClient.files.download({ fileId: project.thumbId });
        if (result.error || cancelled) continue;
        const url = URL.createObjectURL(result.data as Blob);
        urls.push(url);
        setThumbs((current) => ({ ...current, [project.id]: url }));
      }
    })();

    return () => {
      cancelled = true;
      urls.forEach(URL.revokeObjectURL);
    };
  }, [projects, thumbs]);

  async function onDelete(id: string) {
    try {
      await deleteProject(id);
      setProjects((current) => current.filter((project) => project.id !== id));
    } catch (caught) {
      setError(caught instanceof Error ? caught.message : "Could not delete that project.");
    }
  }

  if (loading) return <p>Loading your projects.</p>;
  if (error) return <p role="alert">{error}</p>;
  if (projects.length === 0) {
    return (
      <section>
        <h1>No saved projects yet</h1>
        <button type="button" onClick={() => navigate("/")}>Open the studio</button>
      </section>
    );
  }

  return (
    <section className="projects-grid">
      <h1>Your projects</h1>
      {projects.map((project) => (
        <article key={project.id}>
          {thumbs[project.id] ? (
            <img src={thumbs[project.id]} alt="" width={320} />
          ) : project.thumbId ? (
            <div className="thumb-placeholder">Preview loading</div>
          ) : (
            <div className="thumb-placeholder">No preview</div>
          )}
          <h2>{project.name}</h2>
          <p>{project.settings.cellSize}px cell</p>
          <button type="button" onClick={() => navigate(`/?open=${project.id}`)}>Open</button>
          <button type="button" onClick={() => onDelete(project.id)}>Delete</button>
        </article>
      ))}
    </section>
  );
}

**Google OAuth.** Spec section 8 marks it optional and additive. It is not in any task above. Adding it later is a `socialProviders` block in `worker/auth.ts` plus a button, with no schema change, so deferring costs nothing. Do not add it mid-plan.

**Email verification and password reset.** Both need a sender domain, which the deferred-domain decision means does not exist yet. `emailAndPassword.requireEmailVerification` stays at its default `false` until then. This is a launch gate, not an oversight: shipping signup without verification is fine on `workers.dev`, and not fine on a public product domain.
